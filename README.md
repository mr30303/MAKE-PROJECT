# MAKE-PROJECT — 프로젝트 폴더 생성기

새 프로젝트를 시작할 때 **문서 폴더 구조와 선택적인 빈 소스 폴더를 만들어 주는 Windows 데스크톱 프로그램**입니다. 프로젝트명과 시작 연도를 입력하고 필요한 자료 종류를 선택하면 생성할 구조를 미리 확인할 수 있습니다.

## 주요 기능

- `[시작연도] 프로젝트명` 형식의 문서 폴더 생성
- 설계자료·개발자료·사용자매뉴얼·검수자료·감리자료·카탈로그 선택
- 보관자료와 별도의 빈 소스 폴더 선택 생성
- 생성 미리보기, 최종 확인, 생성 후 폴더 열기
- 기존 대상 덮어쓰기 및 문서·소스 경로 중첩 차단
- 실패 시 현재 작업의 결과를 확인하여 복구하고, 정리하지 못한 경로 안내

**생성 결과는 폴더뿐입니다.** `AGENTS.md`, `STATUS.md`, `프로젝트정보.md` 등의 파일은 생성하지 않으며 Git 초기화·clone·커밋·push·배포도 수행하지 않습니다.

## 실행 방법

Windows와 .NET Framework가 필요합니다. 실행에 소스 코드나 별도 템플릿은 필요하지 않습니다.

1. 이 저장소에서 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `프로젝트생성기.exe`와 `settings.json`을 같은 폴더에 둡니다.
3. EXE를 실행하고 문서 위치·프로젝트명·시작 연도를 입력합니다.
4. 필요한 폴더를 선택한 뒤 미리보기를 확인하고 **프로젝트 생성**을 누릅니다.

현재 배포 EXE에는 코드 서명이 없어 Windows 보안 설정에 따라 실행이 차단될 수 있습니다.

## 생성 예시

시작 연도 `2026`, 프로젝트명 `샘플 프로젝트`, 문서 종류 `설계자료`와 `사용자매뉴얼`, 보관자료를 선택한 경우:

```text
D:\document\
└─ [2026] 샘플 프로젝트\
   ├─ 받은자료\
   ├─ 문서\
   │  ├─ 설계자료\
   │  └─ 사용자매뉴얼\
   ├─ 배포자료\
   └─ 보관자료\
```

소스 폴더도 선택하면 지정한 위치에 별도로 생성합니다. 예를 들어 `D:\source\sample-project`는 내부 파일이 없는 빈 폴더로 만들어집니다.

## 기본 경로 설정

EXE 옆의 `settings.json`을 수정합니다.

```json
{
  "documentRoot": "D:\\document",
  "sourceRoot": "D:\\source"
}
```

설정 파일이 없으면 위 기본 경로를 사용합니다. 화면에서도 경로를 바꿀 수 있으며, 화면에서 변경한 값은 설정 파일에 저장되지 않습니다.

## 개발과 검증

C# / Windows Forms / .NET Framework로 구현되어 있습니다. 외부 패키지 없이 Windows의 .NET Framework C# 컴파일러를 사용합니다.

저장소 루트에서 PowerShell로 실행합니다.

```powershell
# 빌드: 루트의 프로젝트생성기.exe 갱신
.\개발용\build.ps1

# 빌드와 핵심 테스트 실행
.\개발용\build.ps1 -RunTests

# 기존 EXE를 유지하고 임시 경로에서 검증
.\개발용\build.ps1 -RunTests -OutputPath "$env:TEMP\MakeProjectBuild\프로젝트생성기.exe"
```

`개발용\빌드.cmd`로도 빌드할 수 있습니다. 테스트는 임시 폴더에서 생성·경로 충돌·기존 파일 보존·실패 복구 등을 검증합니다.

| 파일 | 역할 |
|---|---|
| `프로젝트생성기.exe` | 실행 프로그램 |
| `settings.json` | 기본 문서·소스 경로 |
| `개발용/Program.cs` | 화면과 사용자 입력 처리 |
| `개발용/GeneratorCore.cs` | 경로 검증, 폴더 생성과 복구 |
| `개발용/GeneratorCoreTests.cs` | 핵심 동작 테스트 |
| `개발용/build.ps1` | 빌드·테스트 실행 |

상세한 사용법과 기존 자료 보호 동작은 [사용방법](사용방법.md)을 참고하세요.
